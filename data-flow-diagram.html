Named gaps — stated honestly
Single point of failure: one person compiles, cleans, and uploads. A sick day delays the board number.
No version control: the workbook is emailed; there is no authoritative copy and no history of what changed.
Manual reconciliation is error-prone: cross-system matching is done by eye; errors surface downstream, if at all.
No lineage or audit trail: a figure on the dashboard cannot be traced to the source record that produced it.

Target architecture — medallion patternFuture state

Three layers, each with one job. Data lands raw, gets cleaned once under controls, and is served from a single certified layer — so the dashboard, the chatbot, and the board deck cannot disagree.

Bronze — raw ingestion

Automated feeds from HRIS, GL, and vendor systems
  • Append-only and immutable — full source fidelity
  • Ingestion timestamp on every row
  • No transformation at this layer

Silver — cleansed & conformed

One set of rules replaces the manual cleaning step
  • Dedupe and type enforcement
  • Conformed dimensions: function, BU, location, wave
  • Slowly-changing dimensions preserve history
  • Quality-rule violations quarantined, never silently dropped

Gold — business-ready

What the dashboard and the board actually consume
  • Curated facts and dimensions, pre-aggregated
  • One certified definition of every metric
  • Row-level security; direct BI consumption
Sources → Bronze → Silver → Gold → Dashboard · chatbot · board reporting
Automated orchestrationScheduled pipelines with retries and failure alerts routed to a named owner.
Data contractsAgreed schema, types, and delivery SLAs with the BPO Hub team — enforced, not assumed.
Quality gates at each layerCompleteness, uniqueness, validity, timeliness, and GL reconciliation checks.
Full lineageEvery dashboard number traces to the source record that produced it.
Version controlAll transformation logic in git; no undocumented manual steps anywhere.
Master data managementFunction and BU names governed centrally so they never drift.
Certified metric layerOne definition per metric — dashboard, chatbot, and board deck cannot disagree.
GovernanceNamed owner per domain, definitions in a catalog, access control, retention policy.
Fresh by defaultDaily or near-real-time refresh with a freshness SLA displayed to every user.

Migration path

Phase 1 · today

Manual Excel, controlled

Fixed template, in-browser validation, and audit-logged uploads — the current tool.

Unlocks: a trustworthy weekly number without any infrastructure spend.
Phase 2

Automated extract to a landing zone

Source systems deliver on a schedule to managed storage; the manual cleaning step is retired.

Unlocks: no single point of failure, and a full history of every delivery.
Phase 3

Full medallion

Contracts, quality gates, lineage, and a certified semantic layer feeding BI directly.

Unlocks: daily refresh, board-grade auditability, and metrics that cannot drift.
